Deine Briefe am großen Bildschirm.

Verbinde die App mit dem Browser. Danach liest du deine Post am Rechner, durchsuchst sie und exportierst, was du brauchst.

In drei Schritten verbunden.

  1. PostSafe auf dem iPhone öffnen.Unten rechts auf dein Profil tippen.
  2. „Mit Web verbinden“ wählen.Die Kamera geht auf.
  3. Den Code hier abfotografieren.Der Browser zeigt deine Ordner.

Der Code oben ist ein Platzhalter: Die Verbindung wird gerade gebaut und lässt sich noch nicht herstellen.
